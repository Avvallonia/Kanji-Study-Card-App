## ✨ Возможности

- 📖 **2136 кандзи** уровней JLPT N5–N1 с чтениями (он/кун) и примерами слов
- 🇷🇺 **Русские переводы** значений и примеров (база Warodai)
- 🔄 **SRS-повторение** — интервальный алгоритм, похожий на SM-2
- ✅ **Три режима тестов**: кандзи → значение, кандзи → чтение, значение → кандзи
- ✍️ **Прописи пальцем** — можно тренировать написание кандзи прямо на экране
- 📊 **Статистика** — прогресс по уровням, streak, счётчик повторений
- 🎚️ **Фильтр по уровням JLPT** через выдвижное меню
- 💾 **Экспорт/импорт прогресса** в JSON
- 📴 **Офлайн-режим** — приложение работает без интернета
- 📱 **Устанавливается на домашний экран** как нативное приложение

## 🚀 Установка

### Android (Chrome)
1. Открой [ссылку на приложение](https://avvallonia.github.io/Kanji-Study-Card-App/)
2. Через пару секунд появится баннер «Установить Kanji Study как приложение?» → **Да**
3. Если баннера нет — меню браузера → **Установить приложение**

### iOS (Safari)
1. Открой [ссылку на приложение](https://avvallonia.github.io/Kanji-Study-Card-App/)
2. Кнопка **Поделиться** (квадрат со стрелкой)
3. **На экран «Домой»** → **Добавить**
4. Запускай с иконки — откроется без адресной строки

### Desktop (Chrome/Edge)
1. Открой сайт
2. Иконка **установки** в адресной строке (⊕ или 📥)
3. Или: меню → **Установить Kanji Study**

## 📖 Как пользоваться

### Изучение
1. Вкладка **«Учить»** — карточки кандзи.
2. Видишь кандзи, чтения, значения, примеры слов.
3. Жми **«Следующий →»**, чтобы перейти к следующему.
4. **«← Предыдущий»** — вернуться назад (например, если забыл).
5. Прогресс автоматически сохраняется, кандзи попадает в SRS-очередь повторения.

### Тесты
- Вкладка **«Тест»** → выбери режим.
- Тест берёт до 20 уникальных кандзи из уже изученных.
- Правильные ответы усиливают интервал повторения, ошибки — сбрасывают.

### SRS — как работает повторение
Каждой карточке присваивается интервал до следующего показа:
- Изучил впервые → +1 день
- Ответил «Следующий» в изучении → автоматически «Норм», интервал растёт
- Ошибся в тесте → интервал сбрасывается, карточка вернётся быстрее
- Ease (коэффициент сложности) подстраивается индивидуально

### Фильтр уровней
- Тап по **☰** в левом верхнем углу — выдвигается меню уровней.
- Можно учить только N5, только N1, или все сразу.

### Статистика
- Вкладка **«Статистика»**.
- Прогресс по каждому уровню отдельно.
- Streak (🔥) — сколько дней подряд занимался.
- Настройка **«Новых в день»** — сколько новых карточек показывать ежедневно.

### Бэкап
- **Статистика → Данные → Экспорт** — сохраняет JSON с прогрессом.
- **Импорт** — восстанавливает из файла.
